Lineage

Two parents: Diablo (Blizzard North, 1996) for the world, classes, items and affixes, and Angband for turn-based, grid-based play. The Diablo rules are ported from the reconstructed 1.09 source (devilution), with Hellfire’s items, spells and classes; code is reused from the author’s earlier TerminalAssassin. See the family tree.

Played here: the Heaven and Hell mod, the game’s own world (a second mod, D1, follows Diablo closely).

Trivia

  • The README is modest: “This won’t win any awards in terms of innovation anytime soon, I know.”
  • The goal: Angband-style play with a modern UI, “played in much shorter burst of time”. (README.md)
  • No to-hit rolls: attacks always connect, and armour absorbs damage. There are no resistances and no ammo. (README.md)
  • Ported Diablo functions keep the 1996 game’s order of random-number calls. (AGENTS.md)
  • Levels include a Town in Hell and a Merchant District; one quest is to find “evidence against humanity”. (levels.rec, quests.rec)

What's unique

  • Diablo’s loot, turn by turn: prefix and suffix affixes, unique items, a Tristram-like town.
  • Mods: the whole game is data (.rec files); a D1 mod replays Diablo’s own tables.
  • Pathfinding, auto-pickup, a multi-window browser layout with inventory, character and log feeds.
  • Choice of lighting (Diablo’s aura or Angband’s carried light) and respawn rules per mod.

Code dive

  • Go, about 73,000 lines in 383 files, drawn with Ebiten; a separate ASCII mode uses tcell.
  • All game data in GNU recutils-style .rec text files under files/mods/.
  • Browser: compiled to js/wasm and embedded; saves go to IndexedDB.

Manual

No separate manual: press F1 in the game for help.

Getting started

  1. Open the game and pick a class; Warrior is simplest.
  2. Talk to the people in town, take the first quest (Meat Jack).
  3. Go down through the Cathedral. Items are picked up automatically.
  4. F5 quick-saves, F9 loads.

Help

No walkthrough exists yet. Follow the quest log; the townspeople point the way.

Cheats

F10 opens the debug menu: go to any level, god mode, complete a quest, spawn a random unique. The console command wizard opens it too. (src/game/root.go)
