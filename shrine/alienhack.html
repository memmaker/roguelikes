Lineage

AlienHack is its own C++ code, “loosely based on AliensRL by Kornel Kisielewicz”, a 2007 seven-day roguelike after the film Aliens. Like that game it casts you as a lone soldier in a labyrinth of predatory aliens. It has no descendants. See the family tree.

Played here: AlienHack 0.9.1 beta (SockPuppet8/Alienhack @ b843d42), compiled to WebAssembly.

Trivia

  • First announced on the Rogue Temple forum in 2018. (Rogue Temple)
  • The author released it into the public domain (CC0). (GitHub)
  • The upstream README says the game has no sound; the sounds in this port are synthesized. (README)
  • Vision is a 90° cone in the direction you face; you can strafe and turn separately. (Zone vision code, README keys)

What's unique

  • Facing matters: you see and shoot in a cone; strafe (z) and turn (x) are separate moves.
  • Ammunition and armour are the resources, not food or spells; armour gets destroyed by acid.
  • Motion tracker pings aliens you cannot see; aliens crawl through vents.
  • A Quick game or a Long game across the colony blocks.

Code dive

  • C++ with Boost (Serialization, Filesystem), about 26,000 lines in 154 files, plus the author's RL-Shared library for the Win32 console.
  • Model and view kept apart: src/Model (actions, objects) and src/Console (interface).
  • This port: the Win32 console replaced by an 80x40 grid routed to map, status, inventory and message windows; WebAssembly; auto-explore on H. Source: memmaker/Alienhack.

Getting started

  1. Open the game, choose Quick Game.
  2. Move with the arrows or numpad; you face the way you move.
  3. f fires, o reloads; keep aliens at range.
  4. H explores; > walks to the stairs.
  5. Enter opens all commands; ? is help. More in Help.

Help

No walkthrough exists. Rules of thumb:

  • Reload before rounding a corner; aliens are fast.
  • Watch the motion tracker and back into corridors to fight.
  • Keep a grenade for crowds and a sidearm for when the primary is empty.

Cheats

No wizard or debug mode in the code. Export save / Import save keeps backups.
