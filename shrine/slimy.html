Lineage

No parent: TSL is Ulf Åström's own C code, a “hacklike” (Roguetemple) that borrows no code from other roguelikes; the only third-party code is the Mersenne Twister random generator. Versions 0.1 to 0.40 ran from 2006 to 2012 (CHANGES.TXT: 40 releases). This port is based on 0.40 from the 2025 GitLab upload of the ArchiveRL collection.

See the family tree (a standalone game). Sources: backloggd, Roguetemple, upstream.

Trivia

  • The name answers a request to “make a giant slimy skeletal rat bat ghoul lichmummy with a severed hand and floating skull”. (Roguetemple)
  • The severed hand and the burning (floating) skull are both monsters in the game. (monster.c)
  • The licence says TSL “is not free software”: the source is there “so you can compile it on any architecture and verify what runs inside your computer”. (LICENSE.TXT)
  • 0.40 rewrote the GUI in Allegro and added animation; 0.39 brought the Underpass, the Laboratory and the Communications Hub. (CHANGES.TXT)
  • A third-party Go port exists. (c0ze/tsl-go)

What's unique

  • Cyberpunk and fantasy mixed: technicians, sentinels, chrome angels and chainsaw ogres next to ghouls, mummies and a dragon.
  • No numbered depth: areas (the Dungeon, the Ominous Cave, the Drowned City, the Catacombs, the Dragon's Lair, the Chapel of Fallen Stars …) are joined by stairs in a graph.
  • Weapons have damage sequences you learn by using them; completing one identifies the weapon.
  • Facets and shapeshifting change the hero's body and abilities instead of experience levels.

Code dive

Plain C, ~50,500 lines in 165 .c/.h files, one directory. Two frontends chosen at compile time: curses (console.c) and Allegro 5 (allui.c, tiles and animation). The tile sheet is indexed directly by the gent_t enum (16 per row). The browser port keeps the console logic and draws the game's own tileset.png.

Manual

The game's own manual, unmodified: README.md (introduction, building, quick start, customizing), and the full history CHANGES.TXT. The in-game help (?) is the real reference; the port's help page lists every key.

Getting started

  1. Press ? for the in-game help and key reference.
  2. Move with hjkl yubn or the numpad; x explores.
  3. Enter opens the command menu, i the inventory.
  4. > walks to the next stair; press again to take it.
  5. S saves and quits; see the help page.

Help

No walkthrough or spoiler guide was found. Rules of thumb from the game: learn weapon damage sequences by fighting, keep a light source, and the win is found in the Chapel of Fallen Stars, reached through the Dragon's Lair.

Cheats

A debug menu exists (debug.c: create item, identify, reveal level, kill all creatures …) but has no default key: only a debug binding in .tsl_conf reaches it, which the web page cannot edit. Saves are deleted when loaded (no save-scumming in the game; the web version autosaves on level changes and removes the save when the run ends); the page's Export/Import could copy a save.
