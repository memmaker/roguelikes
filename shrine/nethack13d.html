Lineage

NetHack is built on the code of Hack. Its README calls it “an integrated version of two major flavors of Hack”: Andries Brouwer's Unix Hack 1.0.3 and Don Kneller's PC Hack. Mike Stephenson merged the two, took the file names from PC Hack, and folded in patches that other players had posted: new classes, fountains, Keystone Kops, spiders, a magic marker. Each addition is still a switch in config.h.

1.3d was the first public release. Later versions (2.x, 3.x) grew from it, and so did the many variants in the family tree. This page's game is “NetHack 1.3d Revived”, a 2007 patch set that makes the 1987 source build on modern Linux.

Trivia

  • 1.3d is the first public release of NetHack; Stephenson approved the posting to comp.sources.games in July 1987. (NetHackWiki)
  • The “Net” is for the Internet, over which the DevTeam worked together. (Wikipedia)
  • Spells, fountains, thrones and turning yourself into a monster all appear here for the first time. (NetHackWiki)
  • Excalibur is already here: name a long sword and dip it into a fountain. (NetHackWiki)
  • The revived edition's README says it came out in 2007, 20 years after 1.3d, for players who remember “when leprechaun were big L”. (README.revived)

What's unique

  • Twelve classes instead of Hack's six: Samurai, Ninja, Priest, Valkyrie, Elf and Healer join the Archeologist, Tourist, Fighter, Knight, Cave-man and Wizard.
  • Spellbooks and prayer. Magic is no longer only in items: learn spells from books, spend energy to cast them, and pray to your god when in trouble.
  • Fountains and thrones. Quaff from, dip into or sit on them, with random good and bad results.
  • Keystone Kops chase you out of a shop you robbed, and throw cream pies.
  • “The wizard may not stay dead!”, says the README: the Wizard of Yendor comes back.

Code dive

  • Language: K&R C, about 32,000 lines in 101 .c/.h files. Files are named in the short PC Hack style: shk.c, dog.c, fountain.c, pray.c.
  • Feature switches: every contributor's addition sits behind a #define in config.h (SPELLS, PRAYERS, KAA, KOPS, FOUNTAINS, …). The tool makedefs reads objects.h and writes the item defines, honouring those #ifdefs.
  • Environment: 4.xBSD and System V Unix on termcap terminals, and MS-DOS with an optional IBM graphics mode. The README's author built it on a Pyramid 98xe.
  • This port: the game's escape codes run through a small VT100 emulator; the map is drawn as tiles in X11 and in the browser (WebAssembly). WebAssembly needed real prototypes for the old K&R functions, and we fixed a missing argument in the “You give … gold” message on the way. Source: memmaker/nethack13d.

Getting started

  1. Open the game, type a name and answer n to choose a class (Samurai or Valkyrie is easiest), or y to get a random one.
  2. Move with hjklyubn or the arrow keys; walk into a monster to attack. _ explores on its own.
  3. Press Enter for a menu of every command, i for the inventory.
  4. Stuck in a dead end? Search with s (or 20s). Press > to walk to the down stairs and take them.
  5. Eat when you are “Hungry”. The full key list is in the in-game guide.

Help

We found no walkthrough for 1.3d. Rules of thumb:

  • Never hit a floating eye in melee. Never eat a cockatrice corpse.
  • Engrave Elbereth in the dust when cornered: most monsters won't step onto it.
  • Pray when your hit points are very low, but not often.
  • Don't steal from shops: the Keystone Kops come.
  • More: NetHackWiki on NetHack 1.3d.

Cheats

  • Wizard mode (nethack -D, for the user named in config.h) exists in the source but can't be reached in the browser: the page doesn't pass -D.
  • Excalibur: name a long sword “Excalibur” and #dip it into a fountain.
  • Save scumming works in the browser: Export save before something risky, Import save if it goes wrong.
