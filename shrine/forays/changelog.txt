Forays into Norrendrin: version history
=======================================

No changelog file ships with the game. This page collects what exists:
the RogueBasin dates, the GitHub release notes and the upstream commit log
(github.com/Forays/ForaysIntoNorrendrin; the public repo starts at 0.8.3).

Oct 2011     Development starts (RogueBasin).
2012-01-28   0.5.0, first public release (RogueBasin).
2014-10-03   0.8.3 (GitHub release). Release notes:
    This version contains both a console-mode ConsoleForays.exe and a 
    fake-console-mode Forays.exe that can have the window resized.  As in 
    previous versions, the game balance has been tweaked relentlessly.  Of 
    note to players of earlier releases, shrines have been reworked and you 
    will be guaranteed one feat per floor if you find all the shrines on 
    that level.  It should be compatible with Mono (uncertain of the 
    version, but the requirement is not steep) and .NET as low as version 
    3.5.
    
2015-11-06   0.8.4, the last release (GitHub release 2015-11-07 UTC). Release notes:
    Here's a quick summary of the big changes:
    - Health and status bars! You can now see health & status effect 
    durations for both you and enemies.
    - Dungeon descriptions! Flavor text for your surroundings now appears 
    at the bottom of the screen.
    - Shrines can now appear at any depth, not just odd-numbered depths. A 
    full set of 5 will still exist on each pair of depths. (1 and 2,  3 and 
    4,  etc.)
    - Monsters now tend to have slightly less health, but slightly more of 
    them will appear.
    - Added 2 new level types, and changed level type rarities - some are 
    now more common than others.
    - More font sizes, to better fit common screen resolutions while 
    fullscreened.
    
2016         Development stops (RogueBasin); last upstream commit 2016-11-13.
